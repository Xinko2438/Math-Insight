## 一、产品背景与解决的核心问题

传统拍照搜题工具普遍存在两大痛点：
1. **重答案、轻诊断**：直接展示标准解答，学生抄完即止，未能定位底层概念盲区或运算跳步错因，缺乏针对性变式巩固。
2. **移动端数学公式录入与校对体验割裂**：OCR 识别复杂分式、根式、方程组时易产生乱码或纯文本降级，学生无法在手机端直观修改分子、分母或矩阵行，且同步阻塞式分析在切后台时极易中断丢失进度。

**Math Insight（错因智诊）** 从产品交互与底层文档协议两端重构了“拍题录题 → 公式原位纠偏 → 异步错因诊断 → 3 道梯度变式巩固 → 错题本复盘”的完整学习闭环。

## 二、核心架构与产品特性

```text
拍照/相册选图 ──► 题干与学生作答分离识别 (math-document-v1)
                       │
                       ▼
        原生底部可视化公式编辑面板 (KaTeX + AST 节点定位)
        [支持分数/根号/上下标/方程组等 11 类结构点选修改]
                       │
                       ▼
        本机多草稿持久化 & 服务端异步任务队列 (原子去重)
                       │
                       ▼
    结构化诊断报告 (考点定位 + 错因步骤拆解 + 3 道分层变式 + 多轮追问)
```

### 1. 题干与作答分离识别协议（`math-document-v1`）
- 单次多模态请求同时提取**印刷题干**与**手写错误作答**，保留原始错误步骤而不擅自修正为标准答案；对字迹模糊区域原位打标提示学生核对。
- 文档模型统一维护行内公式、独立公式块与稳定块级 ID，录题页、报告页、变式练习与多轮追问共用同一套数学排版引擎。

### 2. 原生底部可视化公式编辑器
- 结合 `KaTeX 0.16.47`、`katex-mini` 与 `unified-latex` AST 语法树定位，在小程序端实现无需手写 LaTeX 源码的**点选式公式编辑器**。
- 支持直接在可视化界面中点击修改分子/分母、插入根号与上下标、为方程组动态增删行及多步撤销，修改完成并确认后才原子更新有效文档。

### 3. 少点击（Zero-Friction）异步诊断与防重算控费状态机
- **异步非阻塞体验**：针对微信小程序切后台超 5 秒中断网络请求的限制，采用服务端持久化任务队列与提交快照机制；学生提交分析后可随时切出或继续录入下一题，分析完成后录题页主按钮自动切换为“查看报告”。
- **快照隔离防重复扣费**：每次诊断严格绑定提交时刻的题目与作答快照签名；学生后续微调文本会生成新草稿修订，绝不覆盖历史报告或静默触发二次付费模型调用。

## 三、工程结构

```text
Math-Insight/
├── pages/                  # 小程序核心页面（首页、分栏录题、诊断报告、错题本、学情统计）
├── components/             # 数学富文本渲染组件与底部可视化公式编辑面板
├── server/                 # Node.js 异步诊断任务服务、OCR 协议校验与微信会话门禁
├── utils/                  # math-document-v1 解析器、草稿状态机与本地存储索引
├── tools/                  # 自动化页面逻辑回归、OCR 协议契约测试与多宽度视口走查脚本
└── docs/                   # 产品需求文档（PRD）、数学排版实现规范与验收基线
```

## 四、质量门禁与验证基线

- **公式与文档引擎**：通过 18 项数学文档 AST 编辑测试、18 项结构化 OCR 契约测试及 11 类复杂公式（分式、根式、极限、矩阵、方程组）原生渲染与分子/分母独立修改验证。
- **交互与状态机回归**：通过 40 项页面状态逻辑测试、16 项多草稿与异步任务幂等去重测试，覆盖 `320px / 375px / 390px / 430px` 四种主流移动端视口宽度与 `prefers-reduced-motion` 无障碍动效降级。
