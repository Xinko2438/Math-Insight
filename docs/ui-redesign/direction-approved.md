# 本项目视觉方向与纠正记录

日期：2026-10-31。作用域：错因智诊学生端 UI，不是跨项目审美规则。

## 选择、纠正与最终原型验收

用户原话：“我们要做蓝色的吧，但是这个 A 清透蓝的字体不行”。

该次反馈只确认蓝色方向，否定原字体。之后已修订排印及列表徽标，B、C 只保留为早期对照。

用户随后原话：“也不要有这种类型的图标”。截图红框明确指向最近错题列表左侧的 x、f′、sin 方块徽标。

依据该纠正，A 版最近错题改为直接对齐的文字列表；同类字母装饰不转移到其他组件。相机、返回、导航等直接表达操作的图标不属于截图所指的装饰徽标。没有修改真实错题或后端。

最新验收原话：“不错了，就是这些数字符号什么的还是显得有点紧凑(但是不用继续改示例了)，整体通过”。用户要求先复制并记录 `/neat`，再推进下一步。

状态：蓝色修订原型整体通过，停止修改示例。数字和符号的舒展排印在原生实现中处理；原生代码、模拟器和真机仍分别验收，不能把原型通过写成这些层面的通过。

## 2026-11-01 原生修订范围

用户在指出当前原生界面的 AI 味与局部拥挤后，要求先调研，再使用 huashu-design；调研交付后原话：“继续吧”。本次执行的是同一项目已选蓝色方向的原生迭代，适用 Skill 的“同一项目内已选定方向后的迭代”豁免，不生成或覆盖旧三方向示例。此项登记实施授权，不登记新的视觉接受。

形式依据来自学生任务：录题页是两种录入方式与最近题目；输入页是题干和作答表单；报告页是原题、对应作答和有序思考；错题本是搜索/筛选后的记录；学情页只表达已有错题的统计。均在手机近距离阅读，使用既有常规 UI 字体与蓝色 #3266ed、浅底 #f5f7fb、正文 #182237、辅助字 #647086。以内容和操作分组建立层级，移除固定倾斜公式与反复劝导，不增加虚构指标或功能。

当前原生改动、真实坐标和遗留问题以 PROJECT.md、RESEARCH.md 的实施补记与 background-verification.json 为准。原生最终效果仍需用户判断；已选蓝色不代表这次布局或后续所有设计自动通过。

## 字体修订依据与实现

### 后续校准候选（2026-11-01，已选择 A）

用户反馈当前原生结构“看起来没有什么大的问题”，但有点单调、过于克制；明确喜欢所附旧拍照卡片的设计感，同时认为其文字冗余。此反馈只绑定本项目，不推广为偏好一切装饰，也不恢复被拒绝的 x/f′/sin 字母徽标。

分析后用户“你继续啊”，制作 [三版首页/报告对比](../ui-calibration/index.html)：A 取景卡片、B 题纸与步骤、C 蓝色头部。各版源为 dir-a/b/c.html；[六个首页草稿](../ui-calibration/thumbs.html) 和 [参考板](../ui-calibration/refs.html) 保留候选与来源。展示当时尚未选择，未进入原生替换。

随后用户选择原话：**“A”**。本次选择绑定校准稿 A 的首页取景卡片和报告分步卡片，授权据此落实原生；其余三页沿用已修正的信息结构并协调控件/内容容器风格。不采用 B/C 的开放题纸或全蓝头部。旧 17 项示例保持冻结。原型方向选择、原生技术检查、实际像素与最终接受仍分开；既有换行绘制问题不因选择 A 而自动解除。

### 零记录页面维护（2026-11-01）

用户要求错题本和学情不要显示“还没有东西然后一个按钮”，并明确“没有的数据可以用 0 来替代”。本次沿已选 A 风格维护，适用 Skill 的同项目选定方向后迭代豁免，不重开方向选择或修改冻结示例。形式来自页面任务：错题本保留检索工具和记录数量，学情保留统计结构与零值分类；不添加虚构记录、零值排行名次或装饰徽标。本次编译／逻辑与 HTML 布局检查已通过，原生和真机显示仍待验；不记录为用户已接受本次画面。

随后用户提供真机图，否定零记录／有记录被分成两套布局，并指出“学习”图标接缝。后续统一为：相同的完整考点与错因类别、顺序、两列结构和默认折叠状态；记录数只改变数值和条形长度，不插入条件式错题本按钮或自动展开／重排。具体错因仍可从分类展开查看。学习图标改用闭合的统一描边轮廓，保留原有蓝／灰选中语义。用户确认顶部数字被截是在向上滑动之后出现；该图不作为首次进入导航遮挡的证据，仍检查回到顶部的完整性。此段记录修复要求，不代替本次原生检查或用户接受。

浏览器实际字体检查：旧 A 的主标题为 Microsoft YaHei Bold，29px、请求字重 750、字距 −1px；列表标题请求 600，同样实际选择 Bold。不是字体文件缺失，也不将其误称为宋体。

新版使用无衬线 UI 链：Arial / PingFang SC / HarmonyOS Sans SC / Noto Sans CJK SC / DengXian / Microsoft YaHei / sans-serif。当前 Windows 的中文实际字体由浏览器检查记录于 verification.json；不声称在本机加载了苹方，也不安装或下载新字体。手机使用可用的系统 UI 字体，原生运行仍须另行核对。

标题 28px、500 字重、自然字距；正文与列表标题常规字重，列表 15px；辅助说明 13–14px；公式使用同一套无衬线排印，不再混入 Georgia。层级由字号、留白和蓝色建立，减少整片粗体。

字体与布局细则参考已读取的 [huashu-design 排印原文](https://github.com/alchaincyf/huashu-design/blob/master/references/typography.md)。不将第三方建议的特定字体或数值写入全局规则。
