## 访问与额度

公网服务启用 `MATH_APP_PUBLIC_ACCESS=1`。小程序通过 `wx.login` 取得临时code，后端向微信code2Session确认身份，返回2小时签名会话。仅保存／传递不可逆的身份标识，不向客户端返回AppSecret、session_key或原始OpenID。小程序请求封装合并并发登录，不自动重试模型请求。OCR、后台分析、旧分析和追问均受同一入口保护；健康检查和公开错因库不调用模型。

目前体验上限为每个微信身份每天30次、全服务每天150次模型入口请求，UTC零点重置；失败请求保守计入，防止不确定结果被反复消耗。SQLite保存计数，重启不清空。对相同用户、同一后台任务和同一任务凭据的重试不重复计入额度。额度是调用次数上限，不是精确金额上限。任务查询和删除继续检查不可猜测的任务Token。

此身份机制用于接口访问控制，不实现用户名页面、云端历史同步或旧记录自动归属；同一AppID的有效微信身份可用，不宣称后端已读取微信“体验成员”名单。体验包的可访问范围仍由微信管理后台控制。真实手机号、头像和昵称均不收集。正式对外试用前，仍需完成隐私告知、学生数据保留／删除及未成年人场景验收。

## 维护与回退

`scripts/deploy-server.ps1` 从共享连接真值读取SSH参数，初次部署明确选定源码，不复制node_modules或历史数据。不会覆盖已存在的服务；后续代码更新先检查任务是否空闲、准备新release和校验，再切服务，不能直接重复初次安装脚本。
