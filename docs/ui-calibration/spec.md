# 蓝色视觉表现校准

日期：2026-11-01。用户先要求只分析，随后“你继续啊”授权制作首页/报告构图对比，展示后选择原话 **“A”**。本次选择绑定 A 取景卡片及报告卡片，现据此落实原生；B/C 与备选保留作历史对照，不改被冻结的旧三方向稿。原生检查与最终接受仍单独记录。

## 共同输入

面向学生手机近距离使用：拍照/相册录题、手动录入、复看最近题目、按需展开思考提示与答案。所有完整版使用 390×844 逻辑视口，同一常规无衬线字体、同一示例题/错误作答/两步思考/变式数据。主色沿用 #3266ed，文字 #182237，辅助字 #647086；不加吉祥物、课程、打卡、积分或掌握度。原型不请求相机、微信存储、模型或后台。

首页是行动入口，视觉温度明快；容量为一块拍照入口、手动入口、两条最近题目；视觉形式来自数学题纸与取景框。报告是阅读与思考，温度平静；容量为原题/原作答、三个页签、两步提示与折叠答案；形式来自等式与推导顺序。所有系统区域复用本地 huashu-design 的 ios_frame.jsx，不自画刘海、状态栏或 Home Indicator。
